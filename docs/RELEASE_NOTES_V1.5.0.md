# Release Notes — V1.5.0 Editing Productivity

## Objetivo
Fechar a camada de produtividade do Whiteboard antes de Templates e Smart Layout.

## Entregas
1. Undo/Redo baseado em snapshots estruturais do quadro e Service Graph relacionado.
2. Histórico visual com restauração para qualquer estado recente.
3. Clipboard completo com preservação de hierarquia, grupos e conexões.
4. Cut/Copy/Paste/Duplicate com atalhos.
5. Menu de contexto específico para canvas, item e conexão.
6. Command Palette pesquisável (Ctrl/Cmd+K).
7. Botões Undo/Redo/Histórico no cabeçalho.
8. Compatibilidade retroativa com V1.4.10.
