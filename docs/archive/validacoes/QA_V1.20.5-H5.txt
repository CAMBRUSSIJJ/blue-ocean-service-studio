Release: CSS Import Order Hotfix

OBJETIVO
--------
Eliminar o warning PostCSS/Vite `@import must precede all other statements` causado por `workspace-library-h3.css` ter sido importado depois de regras CSS em `src/style.css`.

CORREÇÃO
--------
- `@import './runtime/workspace-library-h3.css';` movido para o bloco inicial de imports.
- O import agora precede `@tailwind base/components/utilities` e qualquer regra CSS.
- Nenhuma regra visual de `workspace-library-h3.css` foi removida.
- Gate dedicado `v1205h5:css-import-order-smoke` adicionado ao `npm run qa`.
