# Whiteboard Template Engine — V1.5.1

## Objetivo
Transformar templates em blocos reutilizáveis do motor visual, sem duplicar lógica de módulos.

## Capacidades
- Biblioteca com busca e categorias.
- Preview baseado no payload real.
- Inserção parcial no quadro atual.
- Criação de novo quadro a partir do mesmo template.
- Salvar seleção/subgrafo como template.
- Salvar quadro inteiro como template.
- Preservar containers, parent/child, grupos e conexões internas.
- Variáveis de contexto: `{Serviço}`, `{Persona}`, `{Etapa}`.
- Templates pessoais persistidos em `localStorage`.

## Templates iniciais
1. Service Blueprint essencial
2. Journey visual
3. Fluxo de serviço
4. Descoberta e oportunidades
5. Brainstorm de serviço
6. Mapa de processo
