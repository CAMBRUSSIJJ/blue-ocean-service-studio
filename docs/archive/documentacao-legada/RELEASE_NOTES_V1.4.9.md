# Release Notes — V1.4.9

## Whiteboard Visual Objects

Esta versão não adiciona novas abas de marketing ou Service Design. Ela completa os primitives de conteúdo do motor Whiteboard.

### Entregue

- Tipografia de Texto por variante e alinhamento.
- Post-it com tags, conclusão e tamanhos.
- Card enriquecido.
- Shapes básicos.
- Imagem persistida e comprimida.
- Link rico.
- Arquivo de referência.
- Biblioteca de ícones.
- Drag/drop e paste inteligente.
- Inspector contextual por tipo.
- Compatibilidade retroativa com V1.4.8.

### Próxima etapa

**V1.5.0 — Editing Productivity**: undo/redo robusto, clipboard completo, command palette, menu contextual e atalhos de edição.
