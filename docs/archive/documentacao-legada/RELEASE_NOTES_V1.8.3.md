# Release Notes — V1.8.3

**Blueprint Editor Layout Standardization**

- Padroniza o Blueprint Editor sobre o Design System V1.8.1.
- Mantém a Blueprint Home V1.8.2 como ponto de entrada do módulo.
- Adiciona breadcrumb `Blueprints / Serviço` e status no header.
- No modo Blueprint, o documento atual passa a ser identificado no header sem o seletor global de boards.
- Adiciona painel dedicado **Blueprint ▾**.
- Separa configuração do documento do Inspector do objeto.
- Painel Blueprint possui Estrutura, Contexto e Governança.
- Exibe cobertura operacional no painel do documento.
- Permite controlar camadas e linhas semânticas no painel.
- Permite editar nome, Jornada vinculada, responsável e status do Blueprint.
- Mantém configuração avançada disponível sem poluir o caminho principal.
- Renomeia `Configurações do quadro` para `Configurações do canvas`.
- Padroniza títulos do Inspector: Objeto, Relações, Contexto, Aparência e Organização.
- Biblioteca, Camadas, Outline, Inspector e Blueprint Panel tornam-se mutuamente exclusivos.
- Mantém Whiteboard Core 1.0, Journey Studio 1.0, Blueprint Studio 1.0 e Blueprint Home 1.0.
- Migra metadados da V1.8.2.
