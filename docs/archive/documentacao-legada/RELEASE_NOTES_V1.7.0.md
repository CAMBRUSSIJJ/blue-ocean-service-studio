# Release Notes — V1.7.0 Journey Studio 1.0

## Objetivo
Transformar a Journey View do Whiteboard Core em uma experiência de produto dedicada, sem duplicar o motor visual ou os dados do Service Graph.

## Entregas
- modal Journey Studio 1.0;
- edição de nome, responsável e status da Jornada;
- criação/reordenação/arquivamento de etapas;
- ação do cliente por etapa;
- lane Necessidades e Expectativas;
- lane Métricas;
- entidades Need, Expectation e Metric;
- Métrica com valor, unidade, meta e direção;
- Persona ativa e Emotion Curve;
- criação contextual de Touchpoint, Evidência, Problema, Oportunidade e Métrica por etapa;
- compatibilidade V1.6.0 → V1.7.0.
