# Blue Ocean Service Studio — V1.20.5-H16.6

## Research Workflow UX

Esta release refina exclusivamente a experiência de Pesquisa no modo Fundamentos. A ferramenta deixa de repetir o stepper global de fases, troca a subnavegação `Pesquisa | Valor do serviço` por `Pesquisa | Ferramentas` e move os recursos de pesquisa para uma superfície dedicada.

O quadro de Pesquisa agora usa cards com feedback de hover, seleção e arraste. O drag & drop respeita o modelo do serviço: arrastar um Material para Observações prepara uma nota com a origem; arrastar uma Observação para Evidências executa a promoção canônica; arrastar uma Evidência para Aprendizados abre a síntese com a evidência pré-selecionada. Nenhuma nova entidade paralela é criada.

As ações por botão permanecem disponíveis e a interface respeita `prefers-reduced-motion`. Aplicado e Avançado mantêm a experiência profissional existente.
