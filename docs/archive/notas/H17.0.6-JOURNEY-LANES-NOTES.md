# H17.0.6 — Jornada configurável (incremento funcional)

Base: H17.0.5. Alterações restritas ao editor de Jornada, seu modelo de dados e à associação da Dor à etapa.

## Entregue
- Jornada nova ou antiga abre com etapas e zero faixas configuráveis. Informação canônica preexistente não é excluída.
- Menu “Add lane”: Texto, Imagem (URL), Etapa, Ícones, Grade, Divisor, Gráfico de emoções, Embed (link), Ações, Pensamentos, Pontos de contato, Necessidades e Dores.
- Cartões por etapa; edição diretamente na matriz; faixas nomeáveis, reordenáveis, ocultáveis/reexibíveis e removíveis.
- Layout persistido em `journey.mapLayout` pelo mesmo `setGraph`/histórico do serviço. Cartões visuais indexados por ID da etapa.
- Campos Ações e Pensamentos mantêm o vínculo com Stage, emoções editam Stage, e Necessidades e Dores exibem os IDs canônicos vinculados. Registrar Dor na etapa agora preenche `stage.painIds`.
- Visualização detalhada antiga permanece acessível via menu Visualizações.

## Limitações / validações ainda necessárias
- Cartões aceitam um bloco por interseção faixa×etapa; criação de múltiplos cartões independentes por célula não está implementada.
- Ícones, Grade e Etapa usam editor textual neste incremento; imagem por URL e Embed por link (sem upload nem iframe); barra de edição oferece inserção de marcador, não formatação rich-text integral.
- Vínculos existentes podem ser visualizados e novos registros criados pelo painel de detalhes; interface para selecionar entidades canônicas existentes diretamente no cartão ainda não implementada.
- Smoke test estático e parsing TS/TSX passaram. Build/typecheck e E2E em browser não foram concluídos: instalação de dependências `npm ci` não terminou neste ambiente. Execute `npm ci && npm run typecheck && npm run build` antes de distribuição em produção.
