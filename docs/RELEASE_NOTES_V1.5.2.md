# Release Notes — V1.5.2 Whiteboard Smart Layout

## Novo

- 8 algoritmos de layout automático;
- escopo Seleção / Quadro inteiro;
- densidade Compacta / Equilibrada / Ampla;
- Flow orientado por conexões;
- Tree orientada por relações;
- Journey orientado por Etapas;
- Swimlane orientada por camada semântica;
- Radial;

- integração com containers;

- migra preferências de V1.5.1, V1.5.0 e versões anteriores;
