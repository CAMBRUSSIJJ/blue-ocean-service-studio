SERVICE BUILDER ASSISTANT CONTRACTS
- assistant lives inside a truly free Whiteboard and does not require leaving the canvas
- blank Whiteboard remains items={} and edges={} until explicit user action
- starting the assistant creates no Persona, Journey, Stage, Blueprint or other Service Graph entity
- four modes exist: Criar, Entender, Revisar and Melhorar
- assistant state is persisted per Whiteboard
- creation flow covers service definition, objective/boundaries, customer/persona, stages, experience, operation, evidence, problems, metrics, improvements and final review
- user can pause and resume the assistant
- optional evidence/problems/metrics/improvements can be deferred without fabricated content
- methodology Q&A is deterministic in this phase; no generative AI is required
- assistant questions and last answers persist in its board state
- Persona created by assistant is a real Service Graph entity and a Smart Object on the free canvas
- Journey created by assistant is a real empty Journey and remains linked to the current free Whiteboard
- Stage created by assistant is a real Service Graph Stage and a Smart Object on the free canvas
- Frontstage, Backstage, Process and System can be structured while staying in the free Whiteboard
- assistant review reports structure/gaps and does not invent observations
- final completion requires explicit user action
- Home guided entry creates/opens a blank free Whiteboard before starting the assistant
- Whiteboards library provides a dedicated guided creation action
- assistant panel is responsive and only renders in free Whiteboard context
