# V1.20.5-H7.0.3 — Wave Navigation Interaction

## Adicionado
- Cada clique válido na navegação lateral dispara uma ondulação localizada na altura do item clicado.
- A onda inferior Blue Ocean recebe um `surge` curto sincronizado com o clique.
- O item clicado recebe uma crista luminosa breve, sem alterar o estado ativo.

## Preservado
- Navegação H6/H6.1 e ownership das views.
- Organização H7.0.1 da sidebar.
- Paleta azul/ciano H7.0.2, sem verde estrutural legado.
- `prefers-reduced-motion`: usuários com redução de movimento não recebem as animações.

## Limite
- É uma microinteração de navegação, não uma transição de página completa.
