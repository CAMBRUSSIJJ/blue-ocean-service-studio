# Pacote local para Mac e Linux

Baixe **Blue-Ocean-atualizado-Mac-Linux.zip** nesta pasta pelo botão de download do GitHub e extraia todo o conteúdo.

Requer **Python 3**. Não requer Node.js, npm ou compilação.

No Terminal, entre na pasta extraída `Blue-Ocean-atualizado` e execute:

```sh
sh ABRIR.sh
```

Abra **http://127.0.0.1:4173/** e selecione **Abrir workspace local sem conta**.
Mantenha o Terminal aberto durante o uso; pressione Ctrl+C para encerrar.

Antes de atualizar uma instalação existente, exporte um backup pela aplicação.
Os dados locais ficam associados ao navegador e ao endereço usados; se usava
outro endereço ou porta, importe o backup pela interface.

O pacote contém a sidebar contextual com salvamento automático após 800 ms
ou ao sair do campo, feedback discreto de salvamento e metadados recolhidos.
Consulte também o `LEIA-ME.txt` incluído no ZIP.
