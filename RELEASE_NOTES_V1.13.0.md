# V1.13.0 — Blue Ocean Design System

Base: V1.12.0 Runtime & Architecture Stabilization.

## Entregue
- Design Tokens V2 semânticos;
- biblioteca visual permanente para botões, campos, cards, tabs, dialogs, drawers, inspector, badges, estados, tabelas e skeletons;
- primitives React reutilizáveis;
- bridge visual para runtimes legados sem alterar handlers;
- sidebar/header alinhados ao mesmo sistema;
- neutralização do dark-green/beige legado em CSS estrutural;
- foco de teclado e reduced motion padronizados;
- versão geral atualizada para 1.13.0;
- smoke test específico do Design System.

## Fora de escopo
Nenhum módulo funcional novo foi adicionado. Persistência, Service Graph e runtime V1.12.0 foram preservados.
