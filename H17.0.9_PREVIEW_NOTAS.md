# H17.0.9 — prévia técnica de cartões independentes

Base: H17.0.8 AUDIT A2. Escopo intencionalmente limitado à primeira parte da H17.0.9.

## Implementação
- Faixas livres de texto/grade/ícones e etapa aceitam múltiplos cartões por célula; cada cartão possui ID e conteúdo próprios.
- Criação, edição inline e remoção do cartão sem excluir a etapa ou entidades canônicas.
- Faixas vinculadas a dados estruturados (ações/pensamentos/pontos de contato/necessidades/dores) mantêm seu comportamento original.
- Compatibilidade de leitura: lane.cards antigo continua válido. Ao editar a célula, lane.cardItems passa a guardar a lista e lane.cards recebe um espelho textual.
- Exclusão de etapa remove tanto lane.cards quanto lane.cardItems, preservando outras células.

## Executado
- `npm run journey:h1709:test` — aprovado, operações reais de domínio testadas em Node.
- `npm run journey:a2:test` — aprovado, 12 asserções.
- `npm run syntax:check` — aprovado (checagem sintática sem semântica).

## NÃO homologado
- `npm ci --offline` falha: pacote `zod@4.6.5` ausente no cache. É necessária rede para instalar dependências.
- `tsc --noEmit` sem dependências produz erros de resolução de React e tipos; isso não comprova erro ou sucesso de compilação com dependências.
- Sem teste de interface em navegador, recarregamento, drag-and-drop ou formatação rich-text.
- Migração é por leitura compatível e escrita por célula; não há migração global automática.

## Homologação no Linux com internet
`npm ci && npm run typecheck && npm run build && npm run journey:a2:test && npm run journey:h1709:test && npm run dev`

Validar criação de dois cartões na mesma célula, edição separada, remoção, recarregamento, e exclusão da etapa, bem como compatibilidade com mapas antigos.
